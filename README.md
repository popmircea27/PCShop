  🛒 TechShop - E-commerce pentru piese de calculatoare & periferice
📌 TechShop este o platformă modernă de e-commerce unde utilizatorii pot cumpăra piese de calculator, laptopuri și periferice. Proiectul este construit cu cele mai noi tehnologii pentru a oferi o experiență fluidă și sigură.

🚀 Tehnologii utilizate
Frontend 🎨
🔹 React.js 
🔹 Framer Motion (pentru animații fluide și interactive)
🔹 Diverse librării pentru UI și gestionarea stării

Backend 🛠
🔹 Spring Boot (pentru un backend scalabil și rapid)
🔹 Spring Security 🛡 (pentru autentificare și protecția endpoint-urilor)

Baze de date 🗄
🔹 MongoDB (pentru date nestructurate, produse și recenzii)
🔹 MySQL (pentru date relaționale, utilizatori și comenzi)

⚙️ Implementare
🔹 Paradigme utilizate:

🏗 OOP (proiectare bazată pe obiecte, separare clară a responsabilităților)
🔄 Modularizare (cod împărțit logic pentru scalabilitate și mentenanță ușoară)
🔹 Gestionarea backend-ului în frontend:

🔗 Am creat o clasă de servicii care apelează endpoint-urile backend-ului, permițând utilizarea lor ca funcții în frontend.
🔹 Securitate avansată:

🛡 Spring Security folosit pentru autentificare și protecția API-ului.
🔑 Parole criptate în baza de date cu BCrypt.
🌍 Backend protejat împotriva accesului din alte hosturi.
🔹 Arhitectură:

🏛 MVC (Model-View-Controller) pentru backend.
⚡ Proxy Architecture în frontend pentru o operare optimizată a obiectelor.
